# 🚀 Kaip paleisti šią programą

## ✅ 1-as žingsnis: Diegtis Node.js
Turi turėti Node.js. Parsisiųsk iš: **https://nodejs.org/**  
(Pasirinki LTS versiją)

## ✅ 2-as žingsnis: Ispakuoti ZIP
Išarchyvuok šį .zip failą į savo kompiuterį

## ✅ 3-as žingsnis: Paleisti programą
Dvigubai spausk `run.bat` failą →  programa atsidaro!

## 🌐 Kur ji bėga?
Atsidarys naršyklė adrese: **http://localhost:3000**

---

## 💾 Ko jums reikia:
- Node.js (gratis) - https://nodejs.org/
- Šis ZIP failas
- Nieko daugiau!

## ⚙️ Tūrinio aprašymas:
- `run.bat` - paleisti programą
- `server.js` - pagrindinė programa
- `node_modules/` - bibliotekos (jau įdiegtos)
- `public/` - interneto puslapiai
- `data/` - duomenys
